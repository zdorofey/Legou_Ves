# LEGO_Kiosk — исходники и сборка

Это единственный актуальный проект LEGO-экспоната в репозитории.

## Состав

- `app/scale_setup.py` — поиск весов, проверка показаний и сохранение выбранного адреса.
- `app/vesLego.py` — экран киоска и обработка измерений.
- `app/data/` — изображения и шрифт, необходимые приложению.
- `requirements-build.txt` — версии Python-библиотек для запуска и сборки.
- `build.ps1` — собирает Setup и киоск в Windows EXE.
- `download/` — ZIP с готовыми EXE для установки на выставочный ноутбук.

## Сборка на Windows

Нужен Python 3.11 x64 и PowerShell. Из этой папки выполните:

```powershell
py -3.11 -m pip install -r requirements-build.txt
.\build.ps1 -OutputDirectory dist-release
```

Получатся `dist-release\ScaleSetup.exe` и `dist-release\LegoScaleKiosk.exe`. Держите их в одной папке. При настройке Setup создаст рядом `config.json`; не включайте его в общедоступный репозиторий, так как он содержит адрес конкретных весов.

## Запуск без сборки

После установки зависимостей исходники можно запускать напрямую:

```powershell
py -3.11 app/scale_setup.py
py -3.11 app/vesLego.py
```

Настройки для запуска из исходников хранятся в `app/config.json`. Для установки на экспонат используйте готовые EXE из `download/VesyiMirey_LEGO_Windows.zip` или соберите свои.

## Подключение весов

Откройте Setup, нажмите **«Искать весы»**, выберите нужное устройство, нажмите **«Подключить и проверить»**, затем **«Сохранить выбор»**. Если весы не определились автоматически, нажмите **«Показать все»**. Настройщик ищет поддержку GATT `2A9D` среди неизвестных устройств; проверка идёт последовательно и может занять несколько минут.

Киоск читает весовые пакеты от сохранённого адреса и показывает LEGO-эквивалент. Адрес не вшит в EXE.
