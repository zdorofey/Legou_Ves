# Изображения деталей

Изображения упаковываются локально, чтобы экран работал на выставке без доступа к интернету.

- `brick_1x1.png`, `brick_2x2.png`, `brick_2x4.png`, `brick_2x8.png` — созданные для киоска изолированные продуктовые рендеры в PNG с прозрачным фоном.
- Иллюстрация человечка на весах находится в `Assets/Kiosk/idle-minifigure.png` и создана для экрана ожидания.
- Фон и логотип взяты из предоставленной папки `bb`.

Массы деталей: каталог Bricker, карточки 3005, 3003, 3001 и 3007 (каталожные данные с привязкой к BrickLink).
