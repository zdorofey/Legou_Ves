# Экспонат «Весы» — Лего

Первая версия новой программы экспоната. В решении две Windows-программы и общая библиотека:

- **ScaleSetup** — ищет весы, показывает модель/адрес/уровень сигнала и сохраняет выбранное устройство.
- **LegoKiosk** — работает на экране телевизора: ждёт посетителя, показывает фото случайного стандартного кирпичика и количество эквивалентных деталей.
- **ScaleCore** — декодеры Bluetooth, работа с BLE/GATT и хранение настроек.

## Привязка

1. Включите Bluetooth на ноутбуке и батарейки в весах.
2. Откройте `ScaleSetup.exe`, нажмите «Найти весы» и встаньте на нужные весы, чтобы они передали данные.
3. Выберите найденное устройство и нажмите «Сохранить выбор».
4. Запустите `LegoKiosk.exe`.

Настройка сохраняется в `%LOCALAPPDATA%\VesyiMirey\LegoScale\scale.json`. Она остаётся после закрытия приложения и перезагрузки ноутбука. Xiaomi передаёт измерения в BLE-вещании, поэтому для этих протоколов Windows-сопряжение не требуется. У стандартных GATT-весов приложение подключается к профилю измерений.

В основном приложении `Ctrl+Shift+Q` закрывает полноэкранный экран. Для предварительного просмотра без весов запустите `LegoKiosk.exe --demo`.

## Поддерживаемые протоколы

- Xiaomi Mi Smart Scale 2 (в том числе **XMTZC04HM**) — BLE Service Data `181D`.
- Xiaomi Body Composition Scale — BLE Service Data `181B`.
- Весы с Bluetooth SIG Weight Scale Service (`181D`) и характеристикой Weight Measurement (`2A9D`). Для этой группы используется GATT-подключение и разрешение веса из Weight Scale Feature (`2A9E`), если оно доступно.

«Любая модель» автоматически не гарантируется. У некоторых весов закрытый/зашифрованный формат, нестандартная авторизация или протокол, который не передаёт измерения в поддерживаемом стандартном профиле. Для такой модели добавляется новый `IWeightProtocolAdapter` либо отдельный GATT-клиент после захвата рекламных пакетов и измерения с приложения производителя. Настройщик не позволяет сохранить неизвестный формат как рабочие весы.

У `181D` в 10-байтовом пакете младшие биты управляющего байта указывают единицу, бит `0x20` — стабильность, а бит `0x80` — контрольный пакет без нового веса. Для килограммов `0x02` передаёт промежуточный вес, `0x22` — стабильный вес, `0x82`/`0xA2` — состояние без нового значения. Вес декодируется с шагом 5 г. После стабильного или стабильного контрольного пакета заставка возвращается, если в течение 3 секунд не приходит новых распознанных пакетов. У `181B` есть отдельные флаги стабильности и снятия нагрузки.

Для Xiaomi выбрана адресная привязка: основной экран принимает данные только от сохранённого адреса, чтобы не подхватить весы соседнего стенда. Если производитель меняет BLE-адрес устройства, его можно выбрать заново в `ScaleSetup`.

## Расчёт

Для каждого нового посетителя выбирается один из четырёх кирпичиков. Два посетителя подряд не получают один и тот же тип детали. Количество считается так:

```text
округлить(вес в кг × 1000 / масса одного кирпичика в граммах)
```

| Кирпичик | Каталожный номер | Масса для расчёта |
|---|---:|---:|
| 1×1 | 3005 | 0,44 г |
| 2×2 | 3003 | 1,35 г |
| 2×4 | 3001 | 2,32 г |
| 2×8 | 3007 | 4,75 г |

Массы являются каталожными значениями для обычных полноразмерных кирпичиков; фактическая масса слегка меняется между формами/партиями/цветами. Весы Xiaomi округляют измерение крупнее, чем масса одной детали, поэтому количество является наглядным эквивалентом.

## Сборка

Нужен .NET 10 SDK и Windows 10/11. Откройте `VesyiMirey.sln` в Visual Studio или соберите проекты командами:

```powershell
dotnet publish .\src\ScaleSetup\ScaleSetup.csproj -c Release -r win-x64 --self-contained true -o .\dist\ScaleSetup
dotnet publish .\src\LegoKiosk\LegoKiosk.csproj -c Release -r win-x64 --self-contained true -o .\dist\LegoKiosk
```

Картинки и фон находятся рядом с исполняемыми файлами в `Assets`. В выставочном каталоге держите рядом весь каталог `dist`, а не только `.exe`.
