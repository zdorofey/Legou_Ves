# Оптимизированная сборка LEGO-киоска

Оба EXE собраны из исходников в `app/` через `build.ps1`.

- `ScaleSetup.exe` — поиск, проверка и сохранение BLE-адреса.
- `LegoScaleKiosk.exe` — основной киоск.

Положите оба файла в одну папку. Запустите настройщик, сохраните весы, затем запустите киоск. Для самостоятельной сборки см. `../README.md`.
